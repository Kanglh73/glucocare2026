# GlucoCare 2.0
## Windows test
Open this folder in Visual Studio Code, install Live Server, then open index.html with Live Server.

## Install on iPhone
Deploy the whole folder to an HTTPS host such as Netlify. Open the URL in Safari, tap Share, then Add to Home Screen.

## Features
Quick entry, fasting/post-meal records, automatic status, 7/30-day averages, 30-day chart, local smart insights, CSV backup/import, dark mode, offline support.

Data is stored separately on each device. Export CSV regularly. This is a tracking tool, not a medical device.
